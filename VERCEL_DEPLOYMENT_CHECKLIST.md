## Step 1: Prepare Environment Variables

Before deploying, gather these values:

### Required Environment Variables

```env
# 1. DATABASE_URL
# Get from: Neon Dashboard → Connection String
DATABASE_URL=postgresql://user:password@host.neon.tech/dbname?sslmode=require

# 2. GROQ_API_KEY
# Get from: https://console.groq.com → API Keys
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxx

# 3. AUTH_SECRET (NEW!)
# Generate with: openssl rand -base64 32
AUTH_SECRET=<your_generated_secret>

# 4. NEXT_PUBLIC_APP_URL
# Will be: https://your-project.vercel.app
# Leave blank for now, update after first deploy
NEXT_PUBLIC_APP_URL=
```

### Generate AUTH_SECRET

Run this command to generate a secure secret:

```bash
openssl rand -base64 32
```

Copy the output - you'll need it for Vercel.

## Step 2: Deploy to Vercel (Dashboard Method)

### 2.1 Go to Vercel Dashboard

1. Visit: https://vercel.com/new
2. Sign in with GitHub

### 2.2 Import Repository

1. Click **"Import Project"** or **"Add New..."** → **"Project"**
2. Select **"Import Git Repository"**
3. Find **"polarisaistudio/chatbot"** in the list
4. Click **"Import"**

### 2.3 Configure Project

**Framework Preset**: Next.js (auto-detected ✓)

**Root Directory**: `./` (default ✓)

**Build Command**: `npm run build` (auto-detected ✓)

**Output Directory**: `.next` (auto-detected ✓)

**Node Version**: 18.x or higher (auto-detected ✓)

### 2.4 Add Environment Variables

Click **"Environment Variables"** and add all 3 variables:

| Variable Name | Value | Example |
|--------------|-------|---------|
| `DATABASE_URL` | Your Neon connection string | `postgresql://user:pass@...` |
| `GROQ_API_KEY` | Your Groq API key | `gsk_xxxxx...` |
| `AUTH_SECRET` | Generated secret from Step 1 | `uQtfKG/o6TO...` |

**Important**: Leave `NEXT_PUBLIC_APP_URL` empty for now - we'll add it after deployment.

### 2.5 Deploy

1. Click **"Deploy"**
2. Wait 2-3 minutes for build to complete
3. Note your deployment URL: `https://your-project-xxxxx.vercel.app`

## Step 3: Post-Deployment Configuration

### 3.1 Update NEXT_PUBLIC_APP_URL

1. Go to Vercel Dashboard → Your Project → **Settings** → **Environment Variables**
2. Click **"Add New"**
3. Add:
   - **Name**: `NEXT_PUBLIC_APP_URL`
   - **Value**: `https://your-project-xxxxx.vercel.app` (your actual URL)
4. Click **"Save"**

### 3.2 Redeploy

1. Go to **Deployments** tab
2. Click the **"..."** menu on the latest deployment
3. Click **"Redeploy"**
4. Wait for redeployment to complete

## Step 4: Run Database Migrations

The database tables need to be created on your production database.

### Option A: Run Migration Script Locally

```bash
# Set DATABASE_URL to production database
export DATABASE_URL="postgresql://user:pass@host.neon.tech/db?sslmode=require"

# Run migration
node scripts/migrate-db.js
```

### Option B: Run SQL Manually

Connect to your Neon database and run:

```sql
-- Create admin_users table
CREATE TABLE IF NOT EXISTS admin_users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR(255) NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  name VARCHAR(255),
  role VARCHAR(20) NOT NULL DEFAULT 'admin',
  is_active BOOLEAN NOT NULL DEFAULT true,
  created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
);

-- Create feedback table
CREATE TABLE IF NOT EXISTS feedback (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  message_id UUID NOT NULL REFERENCES messages(id) ON DELETE CASCADE,
  conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
  rating INTEGER NOT NULL,
  comment TEXT,
  timestamp TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW()
);

-- Add unique constraint
ALTER TABLE conversations
ADD CONSTRAINT conversations_session_id_unique UNIQUE (session_id);
```

## Troubleshooting

### Build Fails

**Error: Type errors**
```bash
# Run locally to debug
npm run type-check
npm run build
```

**Error: Missing dependencies**
- Check `package.json` is committed
- Check `package-lock.json` is committed

### Runtime Errors

**Error: Database connection fails**
- Verify `DATABASE_URL` in Vercel env vars
- Check Neon database is running
- Test connection string locally

**Error: AUTH_SECRET not set**
- Add `AUTH_SECRET` to environment variables
- Redeploy

**Error: GROQ_API_KEY invalid**
- Verify API key in Vercel env vars
- Check key hasn't expired
- Regenerate if needed

**Error: Admin login fails**
- Check admin user exists in database
- Verify password hash is correct
- Check `AUTH_SECRET` is set

### Widget Not Loading

- Check `NEXT_PUBLIC_APP_URL` is correct
- Verify CORS is configured (should work by default)
- Check browser console for errors

## Scaling Considerations

### Free Tier Limits

**Vercel Free**:
- 100 GB-Hours compute/month
- 100 GB bandwidth/month
- Unlimited deployments ✓

**Neon Free**:
- 0.5 GB storage
- ~1,000 compute hours/month

**Groq Free**:
- 14,400 requests/day
- Rate limited

### When to Upgrade

Upgrade when you hit:
- **1000+ conversations/day** → Groq Pro ($0.20/1M tokens)
- **1GB+ documents** → Neon Pro ($19/month)
- **High traffic** → Vercel Pro ($20/month)
